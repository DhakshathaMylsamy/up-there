# UP THERE — The human body in space

An interactive educational journey exploring human physiology from Earth to orbit and back. Created by [Dhakshatha M K](https://github.com/DhakshathaMylsamy), an undergraduate Biomedical Engineering student. [LinkedIn](https://www.linkedin.com/in/dhakshatha-m-k).

## Run locally
Open `index.html` directly or run `python -m http.server 8000` in this folder and open http://localhost:8000.

## Deploy on GitHub Pages
Create a public repository named `up-there`, upload the contents of this folder to the repository root, then go to Settings > Pages > Build and deployment > Deploy from a branch. Select `main` and `/ (root)`, then Save. The expected URL is https://dhakshathamylsamy.github.io/up-there/ once deployed.

## Source structure
- `index.html`: responsive layout, SVG illustrations and end credits.
- `science.js`: narrative keyframes and references.
- `app.js`: scroll interpolation and interaction logic.

## Scientific scope
Illustrative flight and qualitative physiological responses, not flight telemetry, clinical measurements or validated predictions. See the expandable Scientific sources & assumptions section at the end of the experience.

Creative inspiration: [Neal.fun Space Elevator](https://neal.fun/space-elevator/). Built with AI-assisted coding.
